## Overview

This project explores the question: **Are more complex AI methods always better for clustering?** The CLUBench research compares conventional clustering, deep learning, and foundation-model-assisted approaches. This repository includes an educational Colab demonstration and figures, slides, and a space for the required presentation video.

**Important:** The educational demo is **not** a reproduction of CLUBench's full 24-algorithm, 131-dataset, 178,815-experiment benchmark.
